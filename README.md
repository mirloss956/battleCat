# 貓咪角色圖鑑

以 SwiftUI 製作的《貓咪大戰爭》風格角色圖鑑介面。使用者可以瀏覽三隻貓咪角色，並查看各自於 Lv1、Lv10、Lv30 的進化形態、角色介紹與攻擊方式。

## 功能

- 瀏覽貓咪、長腿貓與坦克貓三位角色
- 切換 Lv1、Lv10、Lv30，檢視對應的名稱、圖片與說明
- 使用左右箭頭、分頁圓點或左右滑動切換角色
- 切換角色時自動回到 Lv1
- 支援直向與橫向版面配置
- 像素風格角色圖片與格線遊戲介面

## 操作方式

| 操作 | 功能 |
|---|---|
| 點選 Lv1／Lv10／Lv30 | 切換角色進化形態 |
| 點選左右三角箭頭 | 切換上一位或下一位角色 |
| 左右滑動角色圖片 | 切換上一位或下一位角色 |
| 點選底部分頁圓點 | 切換上一位或下一位角色（不可直接跳頁，點選目前頁面左側換至上一位、右側換至下一位） |

## 技術

- Swift
- SwiftUI
- `GeometryReader`：依螢幕方向調整版面
- `Canvas`：繪製格線背景
- `@State`：管理目前角色與等級狀態
- `DragGesture`：支援左右滑動手勢切換角色
- `withAnimation`：提供平滑切換動效

## 專案結構

| 檔案 | 用途 |
|---|---|
| `ContentView.swift` | 角色資料、畫面版面與互動邏輯 |
| `MyApp.swift` | App 進入點 |
| `Assets.xcassets` | 角色圖片資源 |

## 如何執行

1. 使用 Xcode 開啟 `hw4261019.xcodeproj`。
2. 選擇 iOS Simulator 或已連接的裝置。
3. 按下 Run（⌘R）建置並執行。

## 圖片資源

專案中的 `Assets.xcassets` 已內建下列 Image Set 資源，可完整顯示所有角色形態：

- `cat1_lv1`、`cat1_lv10`、`cat1_lv30`
- `cat2_lv1`、`cat2_lv10`、`cat2_lv30`
- `cat3_lv1`、`cat3_lv10`、`cat3_lv30`
